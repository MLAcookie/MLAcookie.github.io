    vscode越来越重了，每次启动vscode都会吃一大堆内存，都赶上专门的IDE了
    （Visual Studio都比vscode省内存）
    所以又来折腾编辑器了
    neovim挺好的，但相对来说配置太多太杂，不好迁移
    经常配置lua脚本然后祈祷可以生效
    Helix一开始的开发目标就是IDE，所以很多功能是内置的，配置简单很多

    这里主要使用scoop作为包管理器，其他平台应该相应的包也好找

    安装Helix

    sudo scoop install helix -g

    LSP配置

    Helix内置LSP的支持，对不同的语言，安装需要的LSP即可
    可通过命令行hx --health检查不同语言的支持情况

    常用语言

    C/CPP

    sudo scoop install clangd -g

    CSharp

    sudo scoop install omnisharp -g

    Python

    sudo scoop install ruff -g

    Rust

    sudo scoop install rustup -g
sudo scoop install llvm -g
rustup component add rust-analyzer

    配置文件

    TOML

    sudo scoop install taplo -g

    配置Helix

    注意Windows的配置文件位置%APPDATA%/helix/config.toml
    其他系统在~/.config/helix/config.toml

    # config.toml
theme = "tokyonight_moon"

[editor]
  shell = ["pwsh", "-c"]
  cursor-shape.insert = "bar"

    就这样就可以了，配置非常方便
