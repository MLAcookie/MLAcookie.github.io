    归纳一下windows常安装的东西
    我目前算是包管理重度依赖，基本上所有的软件都靠包管理器管理
    主要用winget和scoop

    winget部分

    配置全局安装行为

    我的习惯让winget的安装都在全局里
    这个不关键，只是方便我找软件的目录

    打开winget的json配置文件

    winget settings

    加上installBehavior还有里面的东西

    {
    "$schema": "https://aka.ms/winget-settings.schema.json",
    "installBehavior": {
        "preferences": {
            "scope": "machine"
        }
    }
}

    实用工具

    # 新的powershell好用，包括历史命令之类的
winget install Microsoft.PowerShell
# windows实用小工具合集，又名windows版本前瞻
winget install Microsoft.PowerToys
# 最好的windows终端
winget install Microsoft.WindowsTerminal
# 众所周知，windows是linux最好的发新版（确信
winget install Microsoft.WSL
# 高级进程查看
winget install Microsoft.Sysinternals.ProcessExplorer
# 好用的IDE
winget install JetBrains.Rider

    日常软件

    # 思题目学习平台
winget install Valve.Steam
# 网易云
winget install NetEase.CloudMusic

    命令面板插件

    # Translator for Command Palette
winget install 9NSHZ9B3KJFW

    scoop部分

    建议全局安装的会带sudo和-g
    如果是win10的话就先安装一个sudo
    win11的话设置 >> 开发者选项里面启用sudo

    scoop install sudo

    添加scoop存储库

    scoop bucket add extras
scoop bucket add nerd-fonts
scoop bucket add version

    实用工具

    # 多线程下载器，scoop也可以调用
sudo scoop install aria2 -g
# 提取安装包文件
sudo scoop install uniextract2 -g
# hex编辑软件，界面清爽
scoop install imhex
# 经典游戏作弊器，有时候用来改一些软件的数值
scoop install cheat-engine
# 写这篇博客就在用的markdown编辑器
scoop install obsidian
# 硬件信息与温度检测
scoop install hwinfo
# 简易文件服务器，快速传文件
scoop install miniserve

    清理用的小工具

    # 文件占用空间可视化，方便快速清理大文件
scoop install wiztree
# 用来卸载有安装包的软件，这个卸载还带清理注册表
scoop install geekuninstaller
# 清理多余的安装包残留
scoop install patchcleaner

    Coding

    sudo scoop install clangd -g
sudo scoop install cmake -g
sudo scoop install xmake -g
scoop install miktex

    # 开源的git图形化管理工具
scoop install sourcegit
# 好用的开源AI Coding工具
sudo scoop install opencode -g

    生 产 力

    # 开源轻量的office套件，足以胜任大部分的情况
scoop install onlyoffice-desktopeditors
# KDE下面的开源的绘画软件，可以用来做图像编辑
scoop install krita
# 开源的面向工业的3DCAD软件
scoop install freecad
# 编写曲谱的软件
scoop install musescore
# Tracker编曲软件
scoop install furnace

    字体

    # 综合用下来适配度最高的字体
sudo scoop install DejaVuSansMono-NF -g
