    让Steam流量走直连

    2025年10月7日星期二

    国内访问一些全球的东西会有一些困难
    而Steam的部分流量会通过国内走
    比如下载和一些云存档功能
    如果规则没写好，让这些流量不走国内，会导致不必要的流量消耗与速度降低
    不同的软件需要不同的配置，某C开头软件的规则可以通过全局扩展脚本添加

    const steamRules = [
  "GEOSITE,category-games@cn,DIRECT",
  "DOMAIN-SUFFIX,steamserver.net,DIRECT",
  "DOMAIN-SUFFIX,cm.steampowered.com,DIRECT",
];

function main(config, profileName) {
  config.rules = [...steamRules, ...config.rules];
  return config;
}

    某V开头软件的需要添加Direct规则，然后这样写

    geosite:category-games@cn,
domain:steamserver.net,
domain:cm.steampowered.com

    这样就可以让Steam下载流量走直连，但让Steam社区之类的走代理
