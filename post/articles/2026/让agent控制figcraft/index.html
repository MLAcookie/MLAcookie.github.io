    让Agent控制FigCraft

    2026年11月15日星期日

    Ai太强了，很多常用的创意软件都有了复刻版
    而且都是净室开发，不太有侵权的可能

    我使用ArtCraft的FigCraft的时候，发现代码中有mcp相关的痕迹
    然后稍微看了看代码，发现其实已经完整实现了mcp的功能
    但软件的界面中没提，Github和网页也没讲怎么用

    软件本身实际上分为figcraft和figcraft-cli
    前者是图形化的软件，也就是给人用的
    后者是一个命令行工具，人也能用，但显然给Ai用更方便
    这边使用scoop安装，这样可以自动配置环境变量，用artcraft-launcher要手动配置

    scoop install figcraft

    对于mcp的情况，建议采用附加模式启动
    首先需要传入命令行参数启动figcraft

    figcraft --control 23333

    这里的23333是指定的端口，随便填一个就可以
    传命令行参数可以通过创建一个快捷方式传入
    然后配置Agent连接到mcp服务器，原始启动命令是

    figcraft-cli mcp --attach 23333

    保持端口号一致即可
    不同的Agent需要的配置文件会不一样，最好是把命令给Ai，让它自己配置
    然后就可以使用了，Agent和用户可以协同工作，非常方便
